1. INDEPENDENT SCIENTIFIC AND CODE REVIEW
Create an evidence trail for each change: original specification, diagnosed
problem, revised source location/hash, scientific rationale, author decision,
synthetic check, screened sample evidence, downstream consequence, open limits.
Classify changes as:
- Required implementation repair: for example prior-unit counts, category gaps
  and missing donor-Hb handling, already requested by Lucas.
- Approved definition correction: female-only parity changes the comparison
  population and must be described explicitly, beyond repairing arithmetic.
- Inference repair preserving the intended comparison: covariance-aware same-fit
  changes and differences of changes, correct clustering and uncertainty.
- Approved additional analyses: both sensitivity populations, component tests
  and within-family Holm comparisons, without selecting by observed findings.
- Proposed methodological/reporting change: independently assess CR2 details,
  primary-model designation and other amendments against the study question.
- Presentation or operational change: no silent change to estimates/definitions.

Inspect the exact sanitized executable closure, not just comments or summaries.
Confirm it corresponds to the validated private source by file bindings and a
documented path-only/semantic comparison. Establish which configuration actually
ran. Review source changes by scientific purpose rather than implementation size.

Review these areas explicitly:
a. Unit/person/admission identity; simultaneous units; one containing admission;
   collision/conflict handling; prior-unit and following-unit boundaries;
   source coverage; first-event selection before outcome/complete-case filters.
b. Every covariate and category, actual exclusions and missingness; all source
   medication indices; natural outcome scales; artifact and influence evidence.
c. Native GLIMMIX design versus HPMIXED fitting: intercept, CLASS reference,
   knots and scoring-row exclusion, column order/scaling, REML convergence,
   random-effect subject, variance boundaries and fixed reference profiles.
d. The custom person-cluster CR2 implementation: whitening and working target,
   contrast span/support, joint category covariance, scalar DF, HTZ, precision
   guards and independently implemented numerical comparisons. Passing the
   producer's own validator is supporting evidence, not independent proof.
e. Pointwise level/change intervals versus direct endpoint contrasts; hypotheses
   for endpoint heterogeneity and whole-trajectory interaction; planned/active
   category families; Holm scope; no substitution of working-model uncertainty.
f. Paired observed windows, equal event weighting, person clustering and direct
   joint covariance; denominators and interpretive separation from fitted changes.
g. Fit-specific complete-case populations, knots and row-weighted reference
   profiles; effects on BASE/FULL comparisons; deterministic tie handling.
h. Legitimate sparse-support/unavailable inference versus implementation failure.
   Check status predicates against source and numerical evidence, including the
   whole-fit suppression rule; never infer clinical validity from a green status.

Representative independent tests need invented known-answer cases, native SAS
comparisons where appropriate, and an independent implementation/reference for
custom inference. Include zero random-intercept variance, saturation/rank loss,
near-singularity, repeated persons across categories, unavailable categories,
partial precision and nonpositive/low degrees of freedom. Retain failed-case
explanations and tolerances; do not reduce a hypothesis family after fitting.
