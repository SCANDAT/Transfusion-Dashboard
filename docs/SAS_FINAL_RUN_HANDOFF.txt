4. DECISIONS ALREADY APPROVED

Primary result: fully adjusted SAME-TRAJECTORY prediction at +60 minutes minus
prediction at -60 minutes. Observed paired change is secondary. A separately
fitted regression of observed changes is not a substitute for this estimand.

Prior-RBC covariate: physical RBC units beginning strictly earlier in the SAME
verified ICU admission; exclude units starting at the index timestamp. Use
complete unit history, not selected index events or repeated measurement rows.

Parity: new analyses among FEMALE donors only. Historical zero includes male
donors; never relabel those estimates as female-only. Missing/unknown donor
sex or parity must not become a known category. Existing code labels donor
sex 1=male, 2=female; validate source coding, do not confuse recipient sex.

Category inference: one overall test of heterogeneity of the -60/+60-minute
change for each factor/outcome, plus all pairwise differences in those changes.
Holm correction within each factor/outcome family for primary fully adjusted
inference. This is not multiplicity control across every outcome, factor,
sensitivity and model. Define and label secondary families explicitly.

Table 1: each verified PERSON once, anchored at their first eligible event,
using age and admission characteristics at that event. Check ties/conflicts;
do not count a person twice because age differs between admissions.

Sensitivity populations:
1. First eligible event per person.
2. No additional RBC unit starting in (index time, index time +12 hours].
   A simultaneous unit at index time is outside this later-unit window, but
   concurrent index-unit exposure requires its own definition/check.

Approved scope: 7 outcomes x (MAIN + 5 factors) x 2 adjustment sets x
3 populations = 252 planned model fits: 84 per population. Both BASE and FULL
are included in both sensitivities. Sparse categories may make a fit/contrast
non-estimable; record explicit status and reasons, never fabricate a result.
Additional artifact/covariance scenarios are not included in 252 and require a
specific decision. This is a fit count, not a runtime estimate.

6.3 Same-fit change inference
For c=x(+60)-x(-60), Var(change)=c' Cov(beta-hat) c.
Equivalently Vpost+Vpre-2*Cov(pre,post), NOT SEpre^2+SEpost^2.
Subtracting a baseline point prediction from absolute CI limits does not create
a CI for change (S2:443-449; S3:519-526). Shared level terms alone do not prove
the covariance sign or how far the old CI is too wide/narrow.

Current S2 combines trajectory pre/post predictions with change/SE/CI from a
SEPARATE observed-change regression (802-835); S3 also substitutes change-model
results (775-784). This does not implement the approved trajectory estimand.

S3:381-399 uses unsupported nonpositional spline bracket syntax in HPMIXED.
HPMIXED DOES support positional ESTIMATE and CONTRAST. Build actual ordered
design-row differences, request coefficient output (/ E), and verify syntax,
class levels, DF, rank, estimability and endpoint identity on installed SAS.
Do not make a statistically different shortcut simply to make the program run.

6.4 Category comparisons
Interaction trajectories, within-category changes, between-category change
differences and overall endpoint heterogeneity must come from the SAME fit.
The full time-by-factor Type 3 test is a different hypothesis; export both
with distinct names. Use a linearly independent full-rank contrast basis for the
omnibus test, not an unchecked redundant matrix of all pairwise differences.
For k available categories expect k changes and k*(k-1)/2 pairwise comparisons,
or explicit non-estimable status. Record multiplicity families and exclusions;
do not change the family after seeing p values. Ordinary unadjusted CIs must
not be labelled Holm-adjusted intervals.

15. EARLIER OVERCLAIMS TO AVOID

- Archive/CSV identity establishes provenance, not valid model assumptions.
- The sample name does not establish random sampling; inspected code uses
  modulo selection.
- A PatientID random intercept already models dependence. Do not repeat the
  earlier claim that all measurement rows were treated as wholly independent.
- Legacy change CIs are unsupported. Without the covariance, 'necessarily too
  wide' or 'non-significance is an artifact' exceeds the recovered evidence.
- Global time-by-factor significance is not endpoint-change heterogeneity or
  practical importance. Do not copy either all-null or all-small-p conclusions.
- Old observed category N/mean/SE summaries alone do not justify heterogeneity
  tests when people recur across events/categories. Do not reuse the earlier
  claimed Bonferroni conclusion without a valid dependence-aware analysis.
- A single contributing row is not necessarily a single person; absence of
  direct IDs still does not make singleton observed summaries publishable.
- Corrected source does not retroactively correct old CSVs. Clearly label
  legacy, reconstructed, development and validated production artifacts.
